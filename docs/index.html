How scoring works
Safety Gate (pass/block) — Any high-severity security finding blocks the skill entirely.
Static Pre-flight (/20) — Scripts parse and import (7), structure exists (5), documentation (3), code quality (5). Measures "does this skill have the parts."
Behavioral Eval (/80) — A/B test: does Claude do better WITH the skill? Score = (with_skill - baseline) pass rate delta. Measures "does this skill actually help."
